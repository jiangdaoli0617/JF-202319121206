## 2. 引脚分配

```
                    STM32F103C8T6 (LQFP48)
        ┌───────────────────────────────────────────┐
   PA0  │                                           │ PB0  ──► RC522 RST
   PA1  │                                           │ PB1
   PA2  │ ──► ESP8266 RX        (USART2_TX)         │ PB2   (BOOT1，勿用)
   PA3  │ ◄── ESP8266 TX        (USART2_RX)         │ PB3   (JTDO，勿用)
   PA4  │ ──► RC522 NSS/CS      (SPI1_NSS)          │ PB4   (NJTRST，勿用)
   PA5  │ ──► RC522 SCK         (SPI1_SCK)          │ PB5
   PA6  │ ◄── RC522 MISO        (SPI1_MISO)         │ PB6  ──► I2C1 SCL ─┬─ DS3231
   PA7  │ ──► RC522 MOSI        (SPI1_MOSI)         │ PB7  ◄─► I2C1 SDA ─┼─ AT24C02
   PA8  │                                           │ PB8  ──► 蜂鸣器      └─ OLED
   PA9  │ ──► 调试 TX           (USART1_TX)         │ PB9  ──► LED 绿
   PA10 │ ◄── 调试 RX           (USART1_RX)         │ PB10
   PA11 │                                           │ PB11
   PA12 │                                           │ PB12 ──► 按键 K1
   PA13 │ ──  SWDIO            (仿真器)             │ PB13 ──► 按键 K2
   PA14 │ ──  SWCLK            (仿真器)             │ PB14 ──► 按键 K3
   PA15 │                                           │ PB15 ──► 按键 K4
        │                                           │ PC13 ──► LED 红
        └───────────────────────────────────────────┘
```

| 外设 | 信号 | 引脚 | 复用功能 |
|------|------|------|---------|
| RC522 | SCK / MISO / MOSI / NSS / RST | PA5 / PA6 / PA7 / PA4 / PB0 | SPI1 + GPIO |
| DS3231 + AT24C02 + OLED | SCL / SDA | PB6 / PB7 | I2C1 |
| 调试串口 | TX / RX | PA9 / PA10 | USART1 |
| ESP8266 | TX→RX / RX←TX | PA2 / PA3 | USART2 |
| 按键 K1~K4 | 输入 | PB12 / PB13 / PB14 / PB15 | GPIO 上拉 |
| 蜂鸣器 | 输出 | PB8 | GPIO |
| LED 绿 / 红 | 输出 | PB9 / PC13 | GPIO |

**引脚避让说明**

- `PA13/PA14` 保留给 SWD 下载调试，任何外设都不得占用，否则无法烧录。
- `PB3/PB4` 复位后默认为 JTAG 的 JTDO/NJTRST，用作普通 IO 需先关闭 JTAG 复用。
  本设计直接避开，无需 remap。
- `PB2` 为 BOOT1，`PC14/PC15` 属低速晶振/备份域，均避开。
- `PC13` 驱动能力弱（仅可灌电流，约 3 mA），红色 LED 须串 ≥ 1 kΩ 限流电阻。

## 3. I2C 总线地址分配

三个从机挂同一条 I2C1，地址互不冲突，这是本设计能用两线驱动三个模块的原因。

| 器件 | 7 位地址 | 8 位写地址 | 说明 |
|------|---------|-----------|------|
| DS3231 | `0x68` | `0xD0` | 固定地址，不可更改 |
| AT24C02 | `0x50` | `0xA0` | A0/A1/A2 全部接 GND |
| SSD1306 | `0x3C` | `0x78` | 部分模块为 `0x3D`，上电扫描确认 |

**上拉电阻**：I2C 需要总线上拉，取 4.7 kΩ 接 3.3V。注意多数模块板载已带上拉
（常见 4.7 kΩ 或 10 kΩ），并联后等效阻值会变小。**若三个模块都自带 4.7 kΩ 上拉，
并联后仅剩约 1.6 kΩ，电流偏大**，此时应只保留一处上拉，其余模块拆掉或改用无上拉的模块。

**总线电容**：I2C 规范要求总线电容 < 400 pF，四根线走线应尽量短，必要时改用屏蔽线。

## 4. 电源设计

WiFi 模块是本系统最容易出问题的部分，多数「莫名其妙复位/连不上」都源于供电。

| 项 | 要求 |
|----|------|
| 3.3V 电源能力 | ≥ 500 mA（ESP8266 发射瞬时电流可达 300 mA） |
| 输入电源 | 5V / 1A 以上，不可用电脑 USB 口直供 |
| ESP8266 去耦 | VCC-GND 就近并联 100 µF 电解 + 0.1 µF 陶瓷 |
| ESP8266 使能 | `CH_PD`(EN) 必须经 10 kΩ 上拉到 3.3V，悬空则不启动 |
| 共地 | 所有模块必须与主控共地 |

**建议做法**：先不接 ESP8266，调通 SPI 与 I2C 外设；外设全绿后再单独给 ESP8266
供电调试，最后合在一起。这样出问题时能快速定位是供电还是逻辑。

## 5. RC522 天线与金属环境

RFID 在实验室金属设备旁易漏读，这是难点 1 的根源。

| 措施 | 效果 |
|------|------|
| 天线面远离金属 ≥ 10 mm | 读卡距离从 0 cm 恢复到 2~3 cm |
| 天线与金属之间垫铁氧体隔磁片 | 可进一步降低涡流损耗 |
| 使用抗金属专用标签 | 贴在金属器材上的推荐方案 |
| 卡片与线圈平行正对 | 而非斜插或贴在边缘 |
| 读卡失败自动重试 3 次 | 覆盖瞬时干扰导致的偶发失败 |

**实测提示**：无遮挡环境下 RC522 读距约 3~5 cm，靠近金属后可能降至 1 cm 以内。
试验箱阶段请把「读卡距离」作为一项记录数据，答辩时是很好的实测素材。

## 6. 接线检查清单

上电前逐项确认，可避免大部分硬件损坏：

- [ ] 所有模块均为 3.3V 供电，未误接 5V（**RC522 与 ESP8266 接 5V 会烧毁**）
- [ ] ESP8266 的 `CH_PD` 已上拉，`VCC/GND` 未接反
- [ ] RC522 的 `NSS` 接 PA4 而非悬空
- [ ] I2C 总线上拉电阻存在，且未因多模块并联而阻值过低
- [ ] 蜂鸣器经三极管驱动，未直接挂在 IO 口
- [ ] SWD 的 `SWDIO/SWCLK/GND` 已引出，便于烧录与调试
- [ ] 所有模块共地
