# 基于 STM32 与 Java 上位机的实验室器材智能出入管理系统

高校实验室器材与小型设备的规范化、智能化管理。用 RFID 替代纸质台账，实现器材入库、借出、归还、
权限校验、状态监测与日志追溯，并通过 WiFi 将记录上传至上位机远程查看。

## 系统架构

```
┌─────────────────────────────── 现场端 ───────────────────────────────┐
│  RC522        DS3231        AT24C02        OLED        按键/声光     │
│  读卡         时钟          配置存储        显示         人机交互     │
│    └────────────┴─────────────┴─────────────┴────────────┘          │
│                        STM32F103C8T6 主控                            │
└───────────────────────────────┬──────────────────────────────────────┘
                                │ USART1 / AT 指令
                        ┌───────┴────────┐
                        │ ESP8266-01S    │  WiFi STA
                        └───────┬────────┘
                                │ TCP Client（局域网）
┌───────────────────────────────┴──────────────────────────────────────┐
│  Java 后端                                                           │
│    TcpServer :9000  ──►  协议解析  ──►  业务服务  ──►  SQLite 落库    │
│                                    └──►  WebSocket :9001 推送        │
└───────────────────────────────┬──────────────────────────────────────┘
                                │ WebSocket
┌───────────────────────────────┴──────────────────────────────────────┐
│  HBuilderX uni-app 前端（器材台账 / 日志查询 / 远程监控）             │
└──────────────────────────────────────────────────────────────────────┘
```

> 一个实验室可部署多台终端（如每个器材柜一台），按 `DEVICE_ID` **分区管理**，
> 各终端只负责一组器材、互不重叠。Java 后端按设备分别维护连接与档案下发。
> 详见 [01 文档 2.1 节](docs/01-需求说明书.md) 与 [02 文档 2.1 节](docs/02-系统架构与通信协议.md)。
>
> 终端用 AT24C02 保存配置、身份卡、器材档案与未上传日志（40 张卡 / 22 件器材 / 36 条日志），
> **断网且断电重启后仍可独立借还**。容量分配见 [07 文档](docs/07-EEPROM存储设计.md)。

## 技术栈

| 层 | 技术 |
|----|------|
| 主控 | STM32F103C8T6、C 语言、Keil MDK、STM32 标准外设库 |
| 总线 | SPI（RC522）、I2C（DS3231/AT24C02/OLED）、USART（调试 + ESP8266） |
| 联网 | ESP8266-01S AT 指令、TCP |
| 后端 | Java 17、Maven、原生 Socket、SQLite |
| 前端 | uni-app（HBuilderX） |
| 版本 | Git |
